# pt — Portuguese NLP++

This repository is the home for all open-source work on **Portuguese** in
the [VisualText](https://github.com/VisualText) organization. Analyzers,
knowledge bases, tools, and experiments for processing the Portuguese
language with [NLP++](https://github.com/VisualText/nlp-engine) live here.

## Contents

| Folder | Description |
|--------|-------------|
| [`parse-pt-br/`](parse-pt-br/) | Bottom-up phrase parser for Brazilian Portuguese. Breaks prose into noun, verb, and prepositional phrases and clauses, disambiguating multi-class words. All rules, nodes, and functions are named in Portuguese. See its [README](parse-pt-br/README.md). |

More Portuguese analyzers and resources will be added over time.

## Related repositories

- [`dict-pt-br`](https://github.com/VisualText/dict-pt-br) — Portuguese dictionary for Brazil.
- [`nlp-engine`](https://github.com/VisualText/nlp-engine) — the NLP++ text-analysis engine.
- [`vscode-nlp`](https://github.com/VisualText/vscode-nlp) — the VisualText VS Code extension for NLP++.
